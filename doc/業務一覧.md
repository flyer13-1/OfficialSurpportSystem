## 1. システム概要

| 項目 | 内容 |
| --- | --- |
| システム名 | OfficialSupportSystem |
| 目的 | レース運営におけるピット作業の監視・記録、エントリー管理、レース運営支援 |
| 構成 | Web サーバ（`server--web` / port 8080）／API サーバ（`sever--api` / port 9000）／ログインアプリ（`other-loginApp`） |
| 主な利用者 | レース運営者・ピット監視員・チーム管理者 |
| データベース | MySQL |

## 2. 業務分類

| 大分類 | 概要 |
| --- | --- |
| ユーザ・認証 | 利用者の登録・ログイン認証・所属管理 |
| マスタ管理 | レースタイトル・組織情報など基準データの整備 |
| エントリー管理 | 出走車両・ドライバ情報の登録および一括取り込み |
| ピット監視・記録 | ピットイン／アウトの時刻、ドライバ交代、給油、タイヤ交換等の記録 |
| データ参照・出力 | 登録データの表示・検索 |
| システム運用 | アクセス制御、サーバ起動・監視、エラーハンドリング |

## 3. 業務一覧（大分類別）

### 3.1 ユーザ・認証業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| U-01 | アカウント登録 | 利用者ID・ニックネーム・パスワードを入力してアカウントを作成する。パスワードは8文字以上、英大小文字＋数字を必須とする | `other-loginApp/node.js/public/regist.html`、`public/a_js/regist.js`、`users` テーブル |
| U-02 | ログイン認証 | 利用者IDとパスワードによるサインイン | `other-loginApp/node.js/public/index.html`、`public/a_js/login.js`、`server--web/routes/login.js`（予定） |
| U-03 | パスワード強度チェック | クライアントサイドでパスワード入力をリアルタイム検証し、要件未充足の間は送信ボタンを無効化する | `login.js` / `regist.js` |
| U-04 | 所属組織の管理 | 利用者が属する団体・チーム情報を保持し、ユーザに紐付ける | `organizations` テーブル、`users.organization_id` |

### 3.2 マスタ管理業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| M-01 | レースタイトル管理 | 開催レースのタイトルを登録・参照する | `race` テーブル |
| M-02 | 組織マスタ管理 | 利用者の所属組織を登録・参照する | `organizations` テーブル |

### 3.3 エントリー管理業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| E-01 | エントリー登録（フォーム） | レース、ピット番号、車番、ドライバA〜F を画面入力で登録する | `server--web/routes/enter.js`（`POST /enter/auto` で API サーバへ転送）、`entry` テーブル |
| E-02 | エントリー一括登録（CSV） | `entry.csv` を `LOAD DATA INFILE` で取り込み、車番・ピット番号・ドライバA〜F を一括登録する | `doc/database/SQLcode.txt`、`entry` テーブル |
| E-03 | エントリー情報参照 | 登録済みエントリーを表示する | `server--web/routes/show.js`（予定）、`entry` テーブル |
| E-04 | エントリー削除 | 誤登録などのエントリーを削除する | `server--web/routes/delete.js`（予定）、`entry` テーブル |

### 3.4 ピット監視・記録業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| P-01 | ピットイン／アウト時刻記録 | 車両がピットへ入った／出た日時を記録する | `pit_log.in_time` / `out_time` |
| P-02 | ドライバ交代記録 | ピットイン時／アウト時のドライバ（A〜F のいずれか）を記録する | `pit_log.in_driver` / `out_driver` |
| P-03 | 給油有無の記録 | 当該ピットでの給油の有無を記録する | `pit_log.refueled` |
| P-04 | タイヤ交換有無の記録 | 当該ピットでのタイヤ交換有無を記録する | `pit_log.tire_changed` |
| P-05 | 備考記録 | ピット作業中の特記事項（トラブル・ペナルティなど）を自由記述で残す | `pit_log.remarks` |
| P-06 | レース・車両との関連付け | ピット記録を `race_id` と `car_num` に紐付ける | `pit_log` の外部キー |

### 3.5 データ参照・出力業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| V-01 | データ表示 | 登録されたエントリー・ピットログ等を画面に表示する | `server--web` の `/show` ルータ（予定） |
| V-02 | 削除操作 | 不要なデータを削除する | `server--web` の `/delete` ルータ（予定） |
| V-03 | DB 接続確認系コマンド | MySQL への接続確認、テーブル一覧、構造確認、バージョン確認等の運用コマンド | `SQLbase` |

### 3.6 システム運用業務

| 業務 ID | 業務名 | 概要 | 関連リソース |
| --- | --- | --- | --- |
| S-01 | アクセス制御（Web） | 許可 IP リスト方式により Web サーバへのアクセスを制限する | `server--web/webserver.js`（`allowedIps`） |
| S-02 | アクセス制御（API） | CORS と Origin チェックにより、Web サーバ（`http://localhost:8080`）からのみ API を受け付ける | `sever--api/apiServer.js` |
| S-03 | Web→API 連携 | Web サーバが受領したフォームデータを API サーバへ POST 転送する | `server--web/routes/enter.js` |
| S-04 | 静的ファイル配信 | `html/` 配下の HTML/CSS/JS を配信する | `server--web/webserver.js`（`express.static`） |
| S-05 | サーバ起動・常駐 | `nodemon` により Web/API サーバを常駐起動する | 各 `package.json` の `start` スクリプト |
| S-06 | 障害時のユーザ通知 | 500 エラー時に管理者連絡を促すメッセージを返す | `webserver.js`（`error500`） |

## 4. 業務とテーブルの対応

| テーブル | 主な業務 | 主要カラム |
| --- | --- | --- |
| `users` | U-01, U-02, U-04 | `id` / `username` / `password_hash` / `nickname` / `organization_id` |
| `organizations` | M-02, U-04 | `id` / `name` |
| `race` | M-01, E-01, P-06 | `id` / `title` |
| `entry` | E-01, E-02, E-03, E-04 | `race_id` / `pit_num` / `car_num` / `driver_A`〜`driver_F` |
| `pit_log` | P-01〜P-06 | `id` / `race_id` / `car_num` / `in_time` / `out_time` / `in_driver` / `out_driver` / `refueled` / `tire_changed` / `remarks` |

## 5. 業務とエンドポイントの対応

| エンドポイント | メソッド | 対応業務 | 備考 |
| --- | --- | --- | --- |
| `/` | GET | S-04 | `main.html` を返却（`server--web/webserver.js:24`） |
| `/login/*` | - | U-02 | ルータ `server--web/routes/login.js`（実装予定） |
| `/enter/auto` | POST | E-01 | フォーム受領 → API 転送（`server--web/routes/enter.js:6`） |
| `/show/*` | - | V-01, E-03 | ルータ `server--web/routes/show.js`（実装予定） |
| `/delete/*` | - | V-02, E-04 | ルータ `server--web/routes/delete.js`（実装予定） |
| API サーバ（port 9000） | - | E-01 受領、DB 反映 | `sever--api/apiServer.js` |
