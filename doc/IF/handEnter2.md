## リクエスト

### クエリパラメータ

### リクエストボディ

```json
{
  "5": {
    "driver": "A",
    "inTime": "2026-05-06T10:00:00+09:00",
    "outTime": "2026-05-06T11:00:00+09:00",
    "tire": true, //boolean
    "oil": false, //boolean
    "note": "メモ"
  }
}
```

- `inTime` / `outTime`: ISO 8601形式（`+09:00`付き）
- `tire` / `oil`: `true` = 交換・補充あり、`false` = なし

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
