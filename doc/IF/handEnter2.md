### リクエストボディ

```json
{
  "5": {
    "driver": "A",//String

    "inTime": "10:00",//String

    "outTime": "11:00",//String

    "tire": "yes",//boolean
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
