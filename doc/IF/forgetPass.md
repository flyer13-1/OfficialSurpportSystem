# 概要

パスワードの再設定をする画面

# インターフェース仕様

送られた利用者IDと会員番号が正しければパスワードを変更する

## API パス

- `/user/password`

## メソッド

- `PUT`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

担当者名はひらがな・カタカナ・漢字を有効化
4-20文字以内

パスワードは半角英数の大文字小文字・6-20文字以内

新しいパスワードが現在のパスワードと同じの場合または事前に登録されたパスワードと同じ場合は再設定不可

全部必須入力です

```json
{
  "username": "あそう太郎", // 担当者名
  "password": "password", //パスワード（平文）
  "newpassword": "password" //新しいパスワード（平文）
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・もし正常終了した場合は空文字
}
```
