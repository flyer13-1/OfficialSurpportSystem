# 概要

パスワードの再設定をする画面

# インターフェース仕様

送られた利用者IDと会員番号が正しければパスワードを変更する

## API パス

- `/user/password`

## メソッド

- `PUT`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

利用者IDは半角英数字の小文字のみ・4-20文字以内
会員番号は半角英数字の小文字のみ
パスワードは半角英数の大文字小文字・6-20文字以内です
全部必須入力です

```json
{
  "username": "20051023", // 利用者ID
  "num": "number" // 会員番号
 "password": "password" //新しいパスワード（平文）
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
