# 概要

パスワード変更画面

# インターフェース仕様

現在のパスワードを知っている利用者が新しいパスワードに変更する。

**パスワードを忘れた場合の運用：**
このAPIではパスワードを忘れた利用者の救済はできない。パスワードを忘れた場合は管理者に連絡し、管理者が手動でDBのパスワードをリセットする運用とする。

## API パス

- `/user/password`

## メソッド

- `POST`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

担当者名はひらがな・カタカナ・漢字を有効化
4-20文字以内

パスワードは半角英数の大文字小文字・6-20文字以内

新しいパスワードが現在のパスワードと同じの場合または事前に登録されたパスワードと同じ場合は再設定不可

全部必須入力です

```json
{
  "username": "あそう太郎", // 担当者名
  "password": "password", //パスワード（平文）
  "newpassword": "password" //新しいパスワード（平文）
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字）
- `400 Bad Request`: パラメータエラー（`msg`: エラー詳細）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

### レスポンスボディ

```json
{
  "msg": "エラー内容"
}
```
