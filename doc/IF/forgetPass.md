# インターフェース仕様

**バックエンド API はない。** フロントエンドが Cognito User Pool に直接
パスワード再設定フロー（Forgot Password）を実行する（common.js の
`cognitoPool` を使用）。Cognito が確認コードを登録メールアドレス宛に送信するため、
現在のパスワードを知らなくても本人確認のうえ再設定できる
（旧仕様の「管理者が手動でリセット」運用は不要になった）。

## フロントエンドの処理（a_js/forgetPass.js）

### ステップ1: 確認コード送信

1. 担当者名（ひらがな・カタカナ・漢字、4〜20文字）を入力
2. `CognitoUser.forgotPassword()` を呼ぶ → 登録メールアドレスに確認コードが届く
3. 成功時: コード入力画面（codeArea）へ切り替え

### ステップ2: 確認コード + 新パスワードで再設定

1. 確認コードと新しいパスワード（半角英数字の大文字小文字を含む、6〜20文字）を入力
2. `CognitoUser.confirmPassword(code, newPassword)` を呼ぶ
3. 成功時: 完了メッセージを表示しログイン画面（index.html）へ遷移
4. 失敗時（コード不一致・期限切れ等）: エラーメッセージを表示。「コードを再送信」で
   `forgotPassword()` を再度呼べる

## バックエンド側の変更

- `POST /user/password` Lambda（changePassword.mjs）は**廃止**。
