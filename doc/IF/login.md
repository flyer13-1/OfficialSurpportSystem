ログイン画面の設定

# インターフェース仕様

## API パス

- `/login`

## メソッド

- `POST`

### クエリパラメータ

なし

### リクエストボディ

担当者名はひらがな・カタカナ・漢字を有効化
4-20文字以内
パスワードは半角英数の大文字小文字を有効化
6-20文字以内
全て必須入力です。

```json
{
  "username": "あそう太郎", // 担当者名
  "password": "password" // パスワード（平文）
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・もし正常終了した場合は空文字
}
```
