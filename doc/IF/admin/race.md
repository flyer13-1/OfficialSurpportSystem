# 管理者画面 IF — レース（race / M-01）

レースタイトルと大会IDを登録・参照・変更・削除する。対象テーブル: `race`（PK `id`）。

- 共通仕様（認証・admin認可・キー命名・ステータスコード）は [index.md](index.md) を参照。
- すべて **認証必要 ＋ admin 限定**。

## フィールド仕様

| フィールド（body） | DB列 | 入力 | 説明 |
|---|---|---|---|
| `raceId` | `id` | 入力（必須） | 非秘密の識別子。管理者が一意な文字列を手動採番（例 `2026fuji_st`）。全APIの `race_id` に使用。半角英数・`_`・`-`、1文字以上 |
| `title` | `title` | 入力（必須） | レースタイトル。**他レースと重複不可**。空文字不可 |
| `todayId` | `today_id` | **自動生成（入力させない）** | **秘密（大会ID）**。**サーバ側で title から自動生成**する。conform（`POST /user/me`）の照合でのみ使用。一覧では伏字表示を推奨 |

- `raceId`（=`id`）は登録後 **変更不可**（PUTでは変えられない）。変更が必要なら削除＋新規登録。

### `todayId` 自動生成ルール

新規レース登録（POST）時にサーバが生成する。フォームには入力欄を置かない。

- **title に使われている文字を1文字以上含める**。
- **15文字以上**にする（既存の大会ID仕様 `/^[A-Za-z0-9\-_!]{15,}$/`、[about the field.md](../about%20the%20path%20of%20api.md) に一致。**バリデーション自体の変更はない**）。
- 他レースと **重複しない**こと（衝突したら再生成）。
- 実装メモ: title は日本語を含み得るため、title 中の **半角英数字を1文字以上**流用し、不足分は予測困難な半角英数で補って15文字以上にする方針とする（title に半角英数が無い場合の流用元はアプリで定める）。

## GET `/race` — レース一覧取得

### リクエスト

- クエリパラメータ: なし
- ボディ: なし

### レスポンス（200）

```json
{
  "msg": "",
  "races": [
    { "raceId": "2026fuji_st", "title": "2026 Round 1", "todayId": "X9KM3ST24HDEMO25Z" }
  ]
}
```

- 0件のときは `races: []`（誤りとはしない）。

## POST `/race` — レース登録（M-01）

### リクエストボディ

```json
{
  "raceId": "2026fuji_st",
  "title": "2026 Round 1"
}
```

- `todayId` は送らない。**サーバが title から自動生成**する（上記「自動生成ルール」）。

### 振る舞い

- `raceId` / `title` の必須・形式を検証。
- `raceId` の重複（PutItem の ConditionExpression `attribute_not_exists(id)`）。
- `title` の重複は **アプリで担保**（登録前に Scan で確認）。
- `todayId` を自動生成（15文字以上・title の文字を1文字以上含む・他レースと非重複）し、保存する。
- レスポンス: `{ "msg": "" }`（生成された `todayId` を返すかは運用次第。秘密値のため既定では返さない）

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| 必須未入力 | 400 | 「未入力の項目があります」 |
| `raceId` 重複 | 409 | 「そのレースIDは既に使われています」 |
| 同名 `title` 重複（M-01-S1） | 409 | 「同名のレースが既に登録されています」 |

## POST `/race/bulk` — レース一括登録（ファイルアップロード：Excel/PDF）

複数レースをまとめて登録する。**Excel/CSV または PDF** をフロントで解析しJSON化して送る（Excel と PDF で同一エンドポイント。PDF は解析結果を画面で確認・修正してから送信）。

### ファイルフォーマット（フロントが解釈する列）

| 列 | → JSON キー | 必須 |
|---|---|---|
| レースID | `raceId` | YES |
| レースタイトル | `title` | YES |

- `todayId` は **行ごとにサーバが自動生成**する（POST `/race` と同じルール）。ファイルには含めない。

### リクエストボディ（フロント→バックエンド）

```json
{
  "races": [
    { "raceId": "2026fuji_st", "title": "2026 Round 1" },
    { "raceId": "2026motegi_st", "title": "2026 Round 2" }
  ]
}
```

### 振る舞い

- 各レコードの `raceId` / `title` の必須・形式を検証。
- ファイル内の `raceId` 重複・`title` 重複を検証（重複があれば取り込みを中断し全体エラー）。
- 既存レースとの `raceId` / `title` 重複も検証する。
- 各行の `todayId` を自動生成（他レース・同ファイル内と非重複）し、一括保存。
- レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| フォーマット不正（列不足・型不正等） | 400 | 「ファイルの形式が規定と異なります」 |
| ファイル内に `raceId` / `title` 重複 | 400 | 「ファイル内に重複するレースがあります」 |
| 既存レースと重複 | 409 | 「既に登録済みのレースが含まれています」 |

## PUT `/race` — レース変更

`raceId` で対象を特定し、`title` を変更する。**`raceId` 自体は変更不可**。

### リクエストボディ

```json
{
  "raceId": "2026fuji_st",
  "title": "2026 Round 1 (改)"
}
```

### 振る舞い

- 対象 `raceId` が存在しなければ 404。
- `title` 変更時は他レースとの重複を検証（同一 `raceId` の現在値は許容＝変更なし）。
- `todayId` は **PUTでは変更しない**（登録時に自動生成した値を維持する。再生成が必要なら削除＋新規登録）。
- レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| 対象が存在しない | 404 | 「対象のレースが存在しません」 |
| `title` 重複（他レース） | 409 | 「同名のレースが既に登録されています」 |

---

## DELETE `/race/{id}` — レース削除

### リクエスト

- パスパラメータ: `id`（= `raceId`）
- ボディ: なし

### 振る舞い（関連データの保護）

- 対象 `raceId` に **エントリー（`entry`）が1件でも紐付く場合は削除不可（409）**。先にエントリーを削除すること。
- （`entry` を削除すれば `start_driver` / `pit_assignment` / `pit_log` も実質残らない想定。安全のため `entry` の存在のみで判定する。）
- 対象が存在しなければ 404。
- レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| 対象が存在しない | 404 | 「対象のレースが存在しません」 |
| エントリーが紐付いている | 409 | 「エントリーが登録されているため削除できません」 |
