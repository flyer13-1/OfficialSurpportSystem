管理者画面（admin.html）と、その背後の管理者APIの設計書。旧版（`../index.md` ほか）は未レビューで実装と大きく乖離していたため、白紙から作り直す。

- 本フォルダを正とする。旧版は、v2 の全章が確定した時点で廃止する（履歴は git に残る）。
- 1章ずつレビュー → 確定 → 次章の順で進める。フロントとバックエンドの両方が終わるまで次の機能に進まない（[nextJob.md](../../../../nextJob.md) の方針）。

## 03章・04章に引き継ぐこと

- 03章: race の削除の扱い（エントリーなどの配下データとの関係）。終了済みの race の配下データは更新できない（01章 R7）
- 04章: 管理者向けの pitlog 参照API。`showAll.mjs` のデータ生成を共通の関数に切り出し、一般向け（終了済みは 403）と管理者向け（`requireAdmin` ＋ race の照合）の2つのハンドラから使う。表示するポップアップとダウンロードボタン（Excel と PDF）では、`showAll.js` / `showAllGimic.js` の表示処理を流用する際に、`entries` などのグローバル名が `admin.js` と衝突しないようにする
