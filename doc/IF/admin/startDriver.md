# 管理者画面 IF — スタートドライバー（start_driver）

各車両のスタートドライバー（pit_num=1 の運転者）を確認・変更・削除する。対象テーブル: `start_driver`（PK `race_id` / SK `car_num`）。

- 共通仕様（認証・admin認可・キー命名・ステータスコード）は [index.md](index.md) を参照。
- すべて **認証必要 ＋ admin 限定**。
- 対象レースは **クエリパラメータ `race_id`** で指定する。
- **新規登録は3通り**：①手入力（1件）②Excel/CSV一括 ③PDF一括（[index.md](index.md) の「入力方法」参照）。個別の確認（R）・変更（U）・削除（D）も提供する。
- ②③のファイルはフロントで解析しJSON化して送る。**PDFは解析結果を画面で確認・修正してから送信**する。

## フィールド仕様

| フィールド（body） | DB列 | 必須 | 説明 |
|---|---|---|---|
| `carNum` | `car_num` | YES | 車番（数値）。SK |
| `driver` | `driver` | YES | スタートドライバーの枠 `A`〜`F` のいずれか1文字。**当該車両の `entry` に存在する（非null）ドライバ枠であること** |

---

## GET `/entry/start-driver?race_id=` — 一覧取得

### リクエスト

- クエリパラメータ: `race_id`（必須）

### レスポンス（200）

```json
{
  "msg": "",
  "startDrivers": [
    { "carNum": 5, "driver": "A" }
  ]
}
```

- 0件のときは `startDrivers: []`。

---

## POST `/entry/start-driver?race_id=` — 1件登録（手入力）

1台ずつフォーム入力で登録する。`carNum`（既存エントリーの車両）と `driver`（A〜F）を指定。

### リクエストボディ

```json
{
  "carNum": 5,
  "driver": "A"
}
```

### 振る舞い

- 対象レース（`race_id`）と当該 `carNum` の `entry` が存在することを確認。
- `driver` が `A`〜`F` で、当該車両の `entry` に **存在（非null）するドライバ枠**であることを検証。
- 保存（同一 `race_id` + `car_num` は上書き）。レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| `driver` が A〜F 以外 | 400 | 「ドライバ枠は A〜F で指定してください」 |
| 指定枠が当該車両のエントリーに存在しない | 400 | 「そのドライバ枠はエントリーに登録されていません」 |
| 対象車両のエントリーが未登録 | 404 | 「対象の車両がエントリーに存在しません」 |

---

## POST `/entry/start-driver/bulk?race_id=` — 一括登録（ファイルアップロード：Excel/PDF）

**Excel/CSV または PDF** をフロントで解析しJSON化して一括登録する。Excel と PDF で同一エンドポイント。PDF は解析結果を画面で確認・修正してから送信する。

### ファイルフォーマット（フロントが解釈する列）

| Excel 列 | → JSON キー | 必須 |
|---|---|---|
| 車番 | `carNum` | YES |
| スタートドライバー枠 | `driver` | YES（`A`〜`F`） |

### リクエストボディ（フロント→バックエンド）

```json
{
  "startDrivers": [
    { "carNum": 5, "driver": "A" },
    { "carNum": 12, "driver": "B" }
  ]
}
```

### 振る舞い

- 対象レース（`race_id`）が存在することを確認。
- 各レコードの `driver` が `A`〜`F` であること、かつ当該 `carNum` の `entry` に **存在（非null）するドライバ枠**であることを検証。
- ファイル内の **車番重複を検証**（重複があれば取り込みを中断し全体エラー）。
- 全件問題なければ一括保存（`BatchWriteItem` 等。同一 `race_id` + `car_num` は上書き）。
- レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| フォーマット不正（列不足・型不正等） | 400 | 「ファイルの形式が規定と異なります」 |
| ファイル内に車番重複 | 400 | 「ファイル内に重複する車番があります」 |
| `driver` が A〜F 以外 | 400 | 「ドライバ枠は A〜F で指定してください」 |
| 指定枠が当該車両のエントリーに存在しない | 400 | 「そのドライバ枠はエントリーに登録されていません」 |
| 対象レースが未登録 | 404 | 「対象のレースが登録されていません」 |

## PUT `/entry/start-driver?race_id=` — 変更（1件）

`carNum` で対象を特定し、`driver`（A〜F）を変更する。

### リクエストボディ

```json
{
  "carNum": 5,
  "driver": "B"
}
```

### 振る舞い

- `driver` が `A`〜`F` のいずれかであることを検証。
- 指定の `driver` 枠が、当該 `race_id` + `carNum` の `entry` に **存在（非null）** することを検証（存在しない枠は不可）。
- 対象 `race_id` + `carNum` の行が存在しなければ 404。
- レスポンス: `{ "msg": "" }`

> 補足: 行が存在しない車両への新規登録は手入力（`POST /entry/start-driver`）または一括登録で行う。PUT は既存行の変更用。

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| `driver` が A〜F 以外 | 400 | 「ドライバ枠は A〜F で指定してください」 |
| 指定枠が当該車両のエントリーに存在しない | 400 | 「そのドライバ枠はエントリーに登録されていません」 |
| 対象が存在しない | 404 | 「対象のスタートドライバーが存在しません」 |

---

## DELETE `/entry/start-driver/{carNum}?race_id=` — 削除

### リクエスト

- パスパラメータ: `carNum`（数値）
- クエリパラメータ: `race_id`（必須）

### 振る舞い

- 対象 `race_id` + `carNum` を削除。存在しなければ 404。
- レスポンス: `{ "msg": "" }`

### 準正常系

| 発生条件 | コード | msg 例 |
|---|---|---|
| 対象が存在しない | 404 | 「対象のスタートドライバーが存在しません」 |
