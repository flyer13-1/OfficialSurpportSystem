
## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容", //準正常系・正常終了した場合は空文字
  "1": [
    "管理ID",
    "担当者",
    "ピット番号",
    "ゼッケン番号",
    "クラス名",
    "チーム名",
    "リタイア",
    "インドライバー",
    "アウトドライバー",
    "ピットイン",
    "ピットアウト",
    "ピットGAP"
  ]
  //という感じですべての情報を含めること
}
```
