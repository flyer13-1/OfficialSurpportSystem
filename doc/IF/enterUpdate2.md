記録変更・リタイア情報更新画面

# インターフェース仕様

ピット記録変更、リタイア情報更新、リタイア取り消しの3種を selection で切り替えて送信する

## API パス

- `/entries/update`

## メソッド

- `PUT`

### リクエストボディ

> **`garageInTime` は廃止した（2026-10-04）。** 既存データに値が入った記録は無いことを確認済み（04章§2.5）。
> 以下の例に残っている `garageInTime` は無効で、リクエストに含めても無視され、レスポンスにも入らない。
> `pitGap` は `inTime` と `outTime` の両方が揃っているときだけ算出し、片方でも欠ければ `null`。

1の時

```json
{
  // １が記録変更　２がリタイア情報更新　３がリタイア取り消し
  "selection": "1",

  "carNum": 2,

  "when": "2", //ピットの回数

  "inTime": "2026-05-06T10:00:00+09:00",

  "outTime": "2026-05-06T11:00:00+09:00",

  "garageInTime": null,

  "outDriver": "A",

  "tire": true, //boolean

  "oil": true, //boolean

  "note": "メモ"
}
```

2の時（リタイア情報更新。RetireTable の reason を更新）

```json
{
  // １が記録変更　２がリタイア情報更新　３がリタイア取り消し
  "selection": "2",
  "carNum": 2,
  "reason": "メモ" // 変更後のリタイア理由。RetireTable の reason カラムを更新
}
```

3の時（リタイア取り消し。RetireTable の retire を false に更新）

```json
{
  // １が記録変更　２がリタイア情報更新　３がリタイア取り消し
  "selection": "3",
  "carNum": 2
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字）
- `400 Bad Request`: パラメータエラー（`msg`: エラー詳細）。`selection` / `carNum` / `when` の未指定、**`carNum` や `when`（ピット回数）が正の整数でない**、変更フィールドが無い、出時刻が入時刻より前
- `404 Not Found`: 対象のピット記録が見つからない／対象のリタイア記録が存在しない（**2026-10-09変更**。それまで 400 で返していたが、入力の形が悪いのか対象が無いのか区別できなかった。`PUT /entries/start-driver` の 404 と揃えた）
- `401 Unauthorized`: 未ログイン（セッション切れ含む）（`msg`: エラー詳細）
- `403 Forbidden`: 担当エリア外の車両／トークンが不正・終了済みのレース（`reason: "race_finished"`。01章 §5.4）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

**数値の検証（2026-10-09追加）:** `carNum` と `when` は正の整数であることを確認する。以前は `Number()` を通すだけだったため、`carNum` が不正だと「担当エリア外の車両です」（**403**）、`when` が不正だと「対象のピット記録が見つかりません」になり、実態（値の形が違う）が伝わらなかった。
