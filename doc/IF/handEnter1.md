# インターフェース仕様

担当者が監視する車両データとドライバーでーたを取得する

## API パス

- `/user/enter/hand`

## メソッド

- `GET`

## リクエスト

### クエリパラメータ

```json
{
  "username": "あそう太郎" // 利用者名
  // セッションから取得
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容", //準正常系・正常終了した場合は空文字
  "carNum":[5, 6, 15, 16, 0, 1, 20],//車両番号
"driver": {
    5: string[],
    6: string[],
    15: string[],
    16: string[],
    0: string[],
    1: string[],
    20: string[]
}

}
```
