# 概要

確認画面からメイン画面に遷移する

# インターフェース仕様

送られた大会IDが正しければメイン画面に遷移する

## API パス

- `/user/me`

## メソッド

- `POST`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

大会IDは半角英数の大文字小文字・１５文字以上
全部必須入力です

```json
{
  "todayId": "2026xcde554" // 大会ID
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字、`raceId` を返す）
- `400 Bad Request`: パラメータエラー、大会IDが一致しない（`msg`: エラー詳細）
- `401 Unauthorized`: 未ログイン（セッション切れ含む）（`msg`: エラー詳細）
- `403 Forbidden`: 終了済みのレース（`msg`: 「終了したレースです」、`reason`: `race_finished`）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

### レスポンスボディ

正常時:

```json
{
  "msg": "",
  "raceToken": "eyJyYWNlSWQiOi...7f2a9c4e..." // 以降のAPIに渡す。フロントは sessionStorage に保存する
}
```

- `raceId` はもう返さない。署名付きの `raceToken` を返し、以降は常に `X-Race-Id` ヘッダーで送る（[raceIdToken.md](raceIdToken.md) §3・§4、01章 R10）。

エラー時:

```json
{
  "msg": "エラー内容"
}
```

終了済みのレース（403）:

```json
{
  "msg": "終了したレースです",
  "reason": "race_finished"
}
```

## 終了済みのレースについて

- `race.finish_date` の翌日 0:00（JST）以降のレースは終了済みとして、大会IDが一致しても入室できない（`403`）。
- 大会IDでの入室は、利用者のサーキットでは制限しない（他サーキットからの応援があるため）。
- フロント（conform）は、`403` を受けたら `msg` を表示して確認画面にとどまる。画面は移動しない。
- 判定の詳細は [admin/v2/01_permission.md](admin/v2/01_permission.md) の §5 を参照。
