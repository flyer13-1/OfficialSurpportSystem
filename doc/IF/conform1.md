# 概要

確認画面からメイン画面に遷移する

# インターフェース仕様

送られた大会IDが正しければメイン画面に遷移する

## API パス

- `/user/entry`

## メソッド

- `POST`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

大会IDは半角英数の大文字小文字・6-20文字以内
全部必須入力です

```json
{
  "todayId": "2026xcde554" // 大会ID
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
