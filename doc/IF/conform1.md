# 概要

確認画面からメイン画面に遷移する

# インターフェース仕様

送られた大会IDが正しければメイン画面に遷移する

## API パス

- `/user/me`

## メソッド

- `POST`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

大会IDは半角英数の大文字小文字・１５文字以上
全部必須入力です

```json
{
  "todayId": "2026xcde554" // 大会ID
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字）
- `400 Bad Request`: パラメータエラー（`msg`: エラー詳細）
- `401 Unauthorized`: 未ログイン（セッション切れ含む）（`msg`: エラー詳細）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

### レスポンスボディ

```json
{
  "msg": "エラー内容"
}
```
