## リクエスト

### クエリパラメータ

なし

### リクエストボディ

```json
{
  "username": "20051023", // 利用者ID
  "password": "password" // パスワード（sha256でハッシュ化するかも）

  //１：富士　2：茂木　3：菅生　4:鈴鹿　5:岡山国際　6:その他　7:無所属
  "circuit": "1" //サーキットの役割
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー
