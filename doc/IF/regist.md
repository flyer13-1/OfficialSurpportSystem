# 概要

登録画面の送受信

# インターフェース仕様

## API パス

- `/user`

## メソッド

- `POST`

## リクエスト

### クエリパラメータ

なし

### リクエストボディ

担当者名はひらがな・カタカナ・漢字を有効化
4-20文字以内
パスワードは半角英数の大文字小文字・6-20文字以内
サーキットは半角数字が下記のパターン入ります。
全部必須入力です

```json
{
  "username": "あそう太郎", // 担当者名
  "password": "password" // パスワード（平文）

  //１：富士　2：茂木　3：菅生　4:鈴鹿　5:岡山国際　6:その他　7:無所属
  "circuit": "1" //サーキット
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
