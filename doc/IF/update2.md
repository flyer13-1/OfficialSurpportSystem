## リクエスト

### クエリパラメータ

### リクエストボディ

1の時

```json
{
  // １が記録変更　２がリタイア
  "selection": "1",

  "carNum": 2,

  "when": "2", //ピットの回数

  "inTime": "2026-05-06T10:00:00+09:00",

  "outTime": "2026-05-06T11:00:00+09:00",

  "garageInTime": null,

  "outDriver": "A",

  "tire": true, //boolean

  "oil": true, //boolean

  "note": "メモ"
}
```

2の時（RetireTable に書き込み）

```json
{
  // １が記録変更　２がリタイア
  "selection": "2",
  "carNum": 2,
  "reason": "メモ" //retire理由。RetireTable の reason カラムに保存
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字）
- `400 Bad Request`: パラメータエラー（`msg`: エラー詳細）
- `401 Unauthorized`: 未ログイン（セッション切れ含む）（`msg`: エラー詳細）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

### レスポンスボディ

```json
{
  "msg": "エラー内容"
}
```
