## リクエスト

### クエリパラメータ

### リクエストボディ

```json
{
  // １が記録変更　２がリタイア
  "selection": "1",

  "carNum": 2,

  "when": "2", //ピットの回数

  "inTime": "2026-05-06T10:00:00+09:00",

  "outTime": "2026-05-06T11:00:00+09:00",

  "noneTime": null,

  "driver": "A",

  "tire": true, //boolean

  "oil": true, //boolean

  "note": "メモ"
}
```

2の時

```json
{
  // １が記録変更　２がリタイア
  "selection": "2",
  "carNum": 2,
  "reason": "メモ" //retire理由
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
