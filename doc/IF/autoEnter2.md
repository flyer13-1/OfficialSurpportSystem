### リクエストボディ

```json
//量が多いの一部だけとする。画面のように一部だけ送られる場合があるがその場合も記録する。要素がない場合は斜線で記録
{
  "5": {
    "driver": "A",//String

    "inTime": "10:00",//String

    "outTime": "11:00",//String

    "tire": "yes",//boolean

    "oil": "no",//boolean

    "note": "メモ"//String
  },

  "6": {
    "driver": "B",//String

    "inTime": "12:00",//String

    "outTime": "13:00",//String
    
    "tire": "yes",//boolean

    "oil": "no",//boolean

    "note": "メモ"//String
  }
}
```

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス
- `400 Bad Request`: パラメータエラー
- `500 Internal Server Error`: サーバーエラー

### レスポンスボディ

```json
{
  "msg": "エラー内容" //準正常系・正常終了した場合は空文字
}
```
