# インターフェース仕様

担当者が監視する車両データとドライバーデータを取得する。autoEnter.html および handEnter.html が使用する。

## API パス

- `/entries/init`

## メソッド

- `GET`

## レスポンス

### ステータスコード

- `200 OK`: 正常なレスポンス（`msg`: 空文字）
- `400 Bad Request`: パラメータエラー（`msg`: エラー詳細）
- `401 Unauthorized`: 未ログイン（セッション切れ含む）（`msg`: エラー詳細）
- `500 Internal Server Error`: サーバーエラー（`msg`: エラー詳細）

### レスポンスボディ

```json
{
  "msg": "",
  "carNum": [5, 6, 15, 16, 0, 1, 20],
  "driver": {
    "5": ["A<br>せきりょうた", "B<br>かんざきあおい", "C<br>きみずかんた"],
    "6": ["A<br>かんじゃに", "B<br>ぶいしっくす", "C<br>すのーまん"],
    "15": ["A<br>koko", "B<br>kesha", "C<br>putbll"],
    "16": ["A<br>かず", "B<br>けんた", "C<br>かんた"],
    "0": ["A<br>noziri", "B<br>mirei", "C<br>JUJU"],
    "1": ["A<br>1gou", "B<br>2gou", "C<br>3gou"],
    "20": ["A<br>灯台", "B<br>強大", "C<br>寛大"]
  }
}
```

- `carNum`: 数値の配列
- `driver`: キーは車番（文字列）、値はドライバー名の配列（A〜F、最大6名）。名前内の `<br>` は表示用改行タグ。EntryTable の `driverA`〜`driverF` から生成
